# VSAG Index Analysis Tool (`analyze_index`)

The canonical documentation for `analyze_index` lives in the website source tree.

Users who only need to inspect an index can install the official wheel and use the Python API or
the `pyvsag-analyze-index` command without compiling VSAG:

```bash
pip install pyvsag
pyvsag-analyze-index --index_path /path/to/index
```
