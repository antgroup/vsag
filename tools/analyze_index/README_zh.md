# VSAG 索引分析工具（`analyze_index`）

`analyze_index` 的规范文档位于网站源码目录。

如果只需要检查索引文件，可以直接安装官方 wheel，无需编译 VSAG 即可使用 Python API 或
`pyvsag-analyze-index` 命令：

```bash
pip install pyvsag
pyvsag-analyze-index --index_path /path/to/index
```
