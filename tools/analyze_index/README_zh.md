# VSAG 索引分析工具（`analyze_index`）

`analyze_index` 的规范文档位于网站源码目录。

无需从源码构建：`pip install pyvsag` 后即可通过 `pyvsag-analyze-index` 命令和
`pyvsag.analyze_index()` Python API 使用相同的分析能力。

- 网站：<https://vsag.io/docs/resources/analyze_index.html>
- 中文网站：<https://vsag.io/docs/zh/resources/analyze_index.html>
