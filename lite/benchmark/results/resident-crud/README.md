# 重复 CRUD 测量

三数据集各 10000 向量、1000 查询行，三存储各三个进程。GIST 仅 998 个不同查询。
每进程 20 轮 × 250 循环，Update→查询→Remove→查询→Add→查询；原索引持续驻留。
合计 405000 次真实修改、405000 次交错查询和 540 对 Save/Load。
修改采用 FP32(.875×current+.125×original donor)，存活数量保持不变。
初末按当前 FP32 输入计算 FP64 穷举真值；Cohere 初始归一化，改值后不归一化。
测量源码身份见[清单](../manifest.json)；本组不包含 Full 对照。
峰值保留原始记录，getrusage 高水位有启动继承风险，不据此推导算法峰值改善。
