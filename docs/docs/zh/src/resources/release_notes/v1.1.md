# VSAG 1.1 版本日志

## 兼容性

VSAG 1.1 移除了已弃用的 HNSW、FreshHNSW 与 DiskANN 索引实现。`Factory` 和 `Engine` 不再注册
`hnsw`、`fresh_hnsw`、`diskann`；通过 C++、C、Python、Node.js 或 `vsag_ext` 创建这些索引时，
现在会进入既有的不支持索引路径。C++ 和扩展 API 返回 `UNSUPPORTED_INDEX`，C API
返回 `nullptr`，语言绑定则抛出对应异常。

这是一次源码与索引产物兼容性变更。相关的公开索引名/参数常量、`IndexType` 成员、
HNSW/DiskANN 参数辅助函数，以及仅供共轭图使用的 `Pretrain`/`Feedback` API 均已移除。
HNSW 或 DiskANN 的 BinarySet、ReaderSet 与文件产物无法由 VSAG 1.1 加载，因为反序列化前必须先创建
对应的索引实现。

由于这些公开 API 移除同时破坏二进制兼容性，共享库使用主版本号与次版本号组成的
SONAME，安装的 CMake package 也要求主、次版本一致。应用必须重新链接 VSAG 1.1，
不能用它原位替换 VSAG 1.0。

移除的公开辅助函数包括 `check_diskann_hnsw_build_parameters()`、
`check_diskann_hnsw_search_parameters()`、`generate_build_parameters()` 与
`estimate_search_time()`。它们仅用于生成或评估已移除旧索引的参数，目前没有替代的自动调优 API；
请按照文档显式配置维护中索引的构建与搜索参数。`Options::num_threads_io()` 与
`Options::set_num_threads_io()` 也已移除，因为该设置只被 DiskANN 使用。

升级前，请使用 VSAG 1.0 读取仍需保留的旧索引产物，再从源向量与 ID 重建为维护中的索引。
通用图 ANN 场景建议迁移到 `hgraph`，倒排场景建议迁移到 `ivf`；其他选项见
[创建索引](../../guide/create_index.md)。仅在仍需访问旧产物时保留 VSAG 1.0；已移除索引不会恢复，
也不会回移到更早的发布分支。
