# 多核高并发检索优化执行记录

## 目标

- 在 WSL 本机完成性能验收。
- 并发 8、16、32 档位的 QPS 提升目标为 `>= 15%`。
- recall 绝对差目标为 `<= 0.01`。
- P99 回归目标为 `<= +10%`。

## 已完成代码

- `StandardHeap` 增加初始预留，并修复容量上限为 64 的边界问题。
- 复用 thread-local 参数 JSON，减少重复解析。
- `SetImmutable` 下为邻居锁路径增加空指针快路。
- 将 `BasicSearcher` 的 `candidate_set` 栈化，减少查询级共享分配。

## 已完成验收工具

- baseline/candidate evaluator 和 `libvsag` 已独立构建并确认动态库隔离；记录 realpath、SHA-256，并用同环境 `ldd` 校验。
- 两个变体共享同一序列化索引，避免索引构建和随机性混入比较。
- 每个 YAML case 使用绝对 `file:///...` JSON 输出；stdout/stderr 只保留诊断信息。
- 同一 evaluator 进程在测量前执行共享配置的 warmup 查询。
- baseline/candidate 按 pair 交替执行，保留真实执行顺序。
- paired acceptance 校验 sample、successful query、error 计数及最小有效 pair 数。
- CLI 返回码区分执行失败和性能验收失败：`0`、`1`、`2`。
- 报告记录 sched affinity、logical CPU 和 oversubscription warning。
