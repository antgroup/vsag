## 任务要求摘要

- 使用 3-5 个公开或项目已有数据集。
- 测试外层并发 `1 / 2 / 4 / 8 / 16 / 32`。
- 每个并发档位记录 QPS、P50、P99、召回率和扩展效率。
- 固定硬件、数据集、索引参数和搜索参数，进行多轮 baseline/candidate 对照。
- 中高并发 QPS 目标较基线提升至少 15%。
- 召回率变化不超过 1%，P99 延迟恶化不超过 10%。
- 若未达到目标，需要保留 profiling 证据和瓶颈分析。

任务原文见 `docs/2026-08-21-VSAG项目任务要求.md`。

## 2026-08-21 O-1 统计 JSON 惰性化与 SIFT 正式 A/B

### 优化内容

按《VSAG高并发检索性能优化方案》O-1 实现：`SearchWithRequest` 每次检索结束时构造
38 个 key 的 nlohmann json 并序列化成字符串写入结果 Dataset（`MakeStatistics(stats).Dump()`），
而评测计时通道从不读取该字符串。本次将统计改为惰性提供者：

- `src/dataset_impl.h`：新增内部 `LazyStatistics` 接口；`DatasetImpl` 支持延迟统计，
  `GetStatistics()` 首次调用时一次性物化（互斥锁保护并发读取）。
- `src/algorithm/hgraph/hgraph.h`、`hgraph_mci.cpp`：MCI 统计字段提取为
  `MCIHybridSearchFields`，eager/deferred 路径共享 `MakeMCIStatistics()` 渲染逻辑。
- `src/algorithm/hgraph/hgraph_search.cpp`：KNN/Range/空结果三条路径改为挂载
  `HGraphLazyStatistics`；`stats` 从栈对象改为 `shared_ptr` 以跨越物化生命周期。
- `src/dataset_impl_test.cpp`：新增惰性统计单元测试（物化一次、按键读取、setter 清除、8 线程并发读取）。

相关提交：`5df6411f perf: 惰性化检索统计 JSON 序列化`、`9c0f584f` 与 `67049e04`
（mutable 成员 const 物化修复）。

O-1 统计惰性化、R1 预取内联、R2 尾处理去回退、R4 sq8 批量核、R5 访问表单位图化、
R6 读偏置全局锁、R7 节点锁跳过、R8/R10 堆优化、R11 图邻居全行预取、R12 内核双块
展开、O-2 统计无锁化；R9a/R9b 负结果已回滚。

### 未达标项的最终瓶颈结论

1. **GloVe-100（+4.9%~11.3%）**：fp32 底层码（404B/向量）随机访问是单查询约
   280μs 的主导项（最终 profile：距离计算+预取+visit 合计 >80%）。任务书固定
   索引参数约束下遍历字节数不可压缩；两次激进实验（预取加倍、IO 内联）回归
   证实常规手段已穷尽。
2. **NYTimes immutable c32（+13.2%）**：immutable 基线本身更快（旧代码亦跳锁），
   相对可挖空间小于 mutable；剩余为纯遍历工作。
3. **高并发衰减**：Amdahl 效应 + 共享资源墙，perf CPI 证据（0.44→0.82）。
